# Frontend Instructions

This is `pokependium-frontend`, a Next.js (App Router) + React application built with TypeScript.

## Standards

For standards, read the package level docs in `docs/`:

- `docs/NEXTJS.md` — Next.js App Router standards
- `docs/REACT.md` — React component standards
- `docs/STYLING_CSS_MODULES.md` — CSS Modules styling standards

For the repository-wide system architecture, see `../../docs/ARCHITECTURE.md`.
For testing conventions, see `../../docs/TESTING-UNIT-STANDARDS.md` and `../../docs/TESTING-E2E-STANDARDS.md`.

Do not treat generated files as source of truth (e.g. `app/types/graphql.ts` produced by GraphQL codegen).
